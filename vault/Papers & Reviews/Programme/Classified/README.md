# Classified Programme question banks

Topic-ordered past questions live here after `/classify <course>`.

```
Classified/<Course>/<Topic>.md
```

`<Course>` is the current filename/join key (e.g. `Foundations of Logic`), never a legacy code. Each note links back to the source PDF page (pdf++) and to the lecture that covers it.

> [!warning] OCR first
> Programme papers in the vault are shortcuts to scans. Empty extract → `- [!]` "needs OCR", not a guessed stem. Build order: [[Crosswalk.md]] first, then one topic note per turn.
