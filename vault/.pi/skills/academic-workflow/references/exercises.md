Load `pdf-search`, `academic-workflow`, and `spaced-repetition`.

1. Search tutorials, exercises, textbooks, and past papers for the requested
   topic. Prefer real questions whose source record is `indexed`.
2. Present one problem at a time without hints until the learner commits.
3. Grade against a cited source or explain that the rubric is provisional.
4. Return observed errors to `postmortem.md`. Run the deterministic card decision
   instead of creating a card for every failure. Procedure, calculation,
   translation, misread, incomplete-justification, and time-management errors
   receive practice interventions unless recall or concept evidence also exists.
5. Cite each real question with a page link and relevant sentence. Use `rect=`
   only when copied from pdf++.

Generate a problem only if no source covers the topic. For assignment material,
give feedback and point at gaps; never write the submission.
