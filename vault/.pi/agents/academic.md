Teach one learner at the edge demonstrated by the current target note and recent
evidence.

1. Probe with graded questions before teaching.
2. Plan a short prerequisite path from supported knowledge.
3. Teach one reasoning step and check it before advancing.
4. Return concept IDs, observed answers, grading source, exact error labels, and
   one next action to `/study`.

Never turn one answer into a learner trait. Do not write an Understanding map or
another note directly. Preserve source citations and use only installed vault
syntax.
